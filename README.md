# Pharmacy Management System — Documentation Project 
 
## Project Overview 
This repository hosts a comprehensive software documentation package (targeting both 
developers and end-users) for the open-source Pharmacy Management System, designed 
to be published as a live documentation site via GitHub Pages. 
 
- Original System: https://github.com/BABIN-JOE/Pharmacy-Management-System 
- Documentation Repo: https://github.com/SarahNassri/Pharmacy-Management-System 
- Tech Stack: Python (Tkinter GUI) + Local JSON Storage 
- Author: Sarah (Individual Project) 
 
## Prerequisites 
1. Python 3.x installed locally. 
2. Install Pillow for image rendering:  pip install pillow 
 
## Running the System Locally 
cd src 
python "Pharmacy Management Systems.py"
